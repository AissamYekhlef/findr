# Findr Backend

FastAPI backend for Findr - a web app for working with tabular data stored in files.

## Development

```bash
make run          # Start dev server on localhost:8000
make test         # Run test suite
make lint         # Lint and format code
make type-check   # Run mypy type checker
```

## API Documentation

Once running, visit `http://localhost:8000/docs` for interactive API docs.
